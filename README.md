# CrimeTown — мод для Minecraft 26.1 (Fabric)

Криминально-сатирический городок: банк с плавающим курсом, казино, оружейная, барыги, ежедневные концерты и путь к званию Босса.

## ВАЖНО: статус сборки

Код написан целиком, но **ни разу не компилировался**: в среде, где он создавался, закрыты Maven-репозитории Fabric/Mojang, а установлена Java 21 (для 26.1 нужна Java 25). Имена API проверены по документации Fabric (переименования в 26.1), но остальное написано по знанию Mojang-имён 1.21.x. Вероятно, при первой сборке будет несколько ошибок компиляции из-за мелких расхождений в сигнатурах. Это нормально: правки обычно однострочные, и каждая подсистема изолирована в своём классе.

Места, где наиболее вероятны расхождения:

| Файл | Что проверить |
|---|---|
| `network/ModNetworking` | `PayloadTypeRegistry.serverboundPlay()/clientboundPlay()` (по порт-гайду Fabric 26.1) |
| `registry/ModItems` | `Item.Properties.setId(...)`, `.component(...)`, `CreativeModeTabEvents.modifyOutputEvent` |
| `registry/ModComponents` | `DataComponentType.builder().persistent().networkSynchronized()` |
| `weapon/GunItem` | `Item.use(...)` -> `InteractionResult`, `getCooldowns().addCooldown(ItemStack, int)`, `hurtServer(...)` |
| `npc/Npcs`, `world/TownBuilder` | `EntityType.create(Level, EntitySpawnReason)`, `Heightmap.Types` |
| `TownEvents` | `ServerPlayConnectionEvents.JOIN` -> `handler.getPlayer()`, `Commands`, `sendSuccess` |
| `client/screen/*` | `Button.builder(...).bounds(...)`, `Screen.rebuildWidgets()` |
| `build.gradle` | блок `loom { splitEnvironmentSourceSets(); mods { ... } }` в новом плагине `net.fabricmc.fabric-loom` |

Сверяйтесь с [Fabric Docs: Porting to 26.1](https://docs.fabricmc.net/develop/porting/) и [Porting to Fabric API 26.1](https://docs.fabricmc.net/develop/porting/fabric-api).

## Сборка

Нужны **JDK 25** и интернет.

```
gradle wrapper --gradle-version 9.4.0     # один раз, чтобы получить gradlew
./gradlew build                           # jar в build/libs/
./gradlew runClient                       # тест клиента
./gradlew runServer                       # тест выделенного сервера
```

Можно просто открыть папку в IntelliJ IDEA 2025.3+ как Gradle-проект.

Версии заданы в `gradle.properties` (Minecraft 26.1.2, Loader 0.19.3, Fabric API 0.155.3+26.1.2, Loom 1.15-SNAPSHOT). Для 26.1.x отдельная версия не нужна: меняйте `minecraft_version` и `fabric_api_version`.

## Как играть

1. Создайте мир с установленным модом. **При первом заходе рядом со спавном (в 20 блоках к востоку) автоматически строится город.** Повторно в креативе: `/crimetown build`. Координаты: `/crimetown info`.
2. **Валюта:** золотой слиток < алмаз < незеритовый слиток.
3. **Банк (северо-запад), Кассир:** ПКМ по нему. Обмен между всеми тремя валютами. Курс алмаза и незерита меняется раз в игровые сутки (±12% за шаг, коридор ±30% от базы), в окне стрелки ▲/▼. Комиссия 5%, поэтому круг обменов всегда в минус.
4. **Казино (северо-восток):** ПКМ по морскому фонарю (слот-машина). Ставка в любой из трёх валют, RTP около 91%, три «СЕМЁРКИ» дают x50 и объявляются на весь сервер.
5. **Оружейная (юго-запад):** пистолет, дробовик, автомат и патроны. **ПКМ — выстрел, Shift+ПКМ — перезарядка.** Есть разброс, отдача камеры и звуки. Выстрел в городе злит Вышибал (железные големы).
6. **Барыги (в переулках):** три «вещества» с безумными комбинациями эффектов, частицами и «отходняком» (Медлительность, Голод, Слабость). Хулиганы (жители с именем «Хулиган») крадут золото при сближении; убейте вора, и золото выпадет.
7. **Сцена (центр):** каждые игровые сутки с наступлением вечера выходит новый певец со случайным именем, играет мелодия, летят ноты, жители собираются у сцены.
8. **Мэрия (юго-восток):** выкупайте доли Банка (64), Казино (48), Оружейной (32) за незерит. Перекупка у другого игрока дороже на 25% за каждую сделку, а прежний владелец получает половину цены. Дивиденды копятся ежедневно, забираются у Мэра. **Все три доли у одного игрока = Босс:** доход x1.5, две личные охранницы-голема, Корона Олигарха.

## Архитектура

```
src/main   общий и серверный код (без клиентских классов)
  economy/     Currency, CurrencyHelper, TownData (JSON-сохранение), EconomyService
  casino/      SlotLogic
  weapon/      GunType, GunItem
  drug/        DrugType, DrugItem, DrugService
  shop/        Shop (списки предложений, общий для сервера и клиента)
  progression/ Business, ProgressionService (акции, Босс, доход, охрана)
  npc/         Npcs (спавн по тегам), GuardService, SpawnService
  concert/     ConcertManager
  world/       TownBuilder (процедурная постройка города)
  network/     ActionPayload, ScreenPayload, RecoilPayload, ActionHandler, ModNetworking
  registry/    ModItems, ModSounds, ModComponents
src/client  только клиент: CrimeTownClient, экраны (Bank/Slot/Mayor/Shop), ScreenRouter
```

Сервер авторитетен: клиент шлёт только «нажата кнопка N», а проверку денег, дистанции до города и выдачу делает сервер.

## Осознанные упрощения (чего НЕТ)

- **NPC и мобы — ванильные существа с тегами**, а не кастомные типы сущностей: так не нужны рендереры и модели, и мод не ломается на сервере. Внешне это жители и железные големы с именами.
- **Город строится кодом при первом заходе**, а не через jigsaw/structure_set в генерации мира. Город один на мир.
- **«Сутки» считаются по времени игры** (`getGameTime() / 24000`), а не по времени суток, поэтому сон не ускоряет курсы и концерты.
- **Шейдер-искажений нет**: эффекты веществ дают тошноту (ванильная качка экрана) и частицы.
- **Рулетки, контрактов и HUD с курсом нет.** Курс виден в окне банка, доход копится у Мэра.
- Музыка концерта — мелодия на ванильных звуках нотного блока, свои `.ogg` не нужны. Звуки выстрелов тоже собраны из ванильных событий в `sounds.json`; замените их на свои `.ogg` по желанию.
- Текстуры предметов — сгенерированные заглушки 16×16.
- Языковые файлы покрывают предметы. Тексты интерфейса пока зашиты по-русски в коде.
